## 🗺️ How to Download & Install
1. **Visit the Releases Page:** Go to the [Releases Page](https://github.com/Shrejalraut0746/Crystal-Glass/releases) to find the latest version of Crystal-Glass.
2. **Choose a Theme:** Browse through the available themes. Click on the one you like to see more details.
3. **Download the Theme:** Once you have chosen a theme, click on the download link associated with that theme. The file will usually be in a `.zip` format.
4. **Unzip the File:** Locate the downloaded `.zip` file on your computer. Right-click on it and select "Extract All" to unzip the contents.
5. **Upload to Your Website:** Access your website’s backend. Find the section where you can manage themes or upload files. Follow the instructions provided by your website platform to upload the newly extracted files.
6. **Activate the Theme:** Once uploaded, make sure to activate the theme. Every platform will have a slightly different process, so refer to your platform's documentation if you need help.
