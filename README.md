# Crystal-Glass

A collection of **website themes** designed to apply a modern "crystal glass" aesthetic. These themes are implemented using pure CSS and are intended for use on various websites.

## Themes
- **facebook.css**: Crystal-Glass theme for Facebook.
- **google.css**: Crystal-Glass theme for Google.
- **mail.google.css**: Crystal-Glass theme for Gmail.
- **messenger.css**: Crystal-Glass theme for Facebook Messenger.
- **youtube.css**: Crystal-Glass theme for YouTube.
